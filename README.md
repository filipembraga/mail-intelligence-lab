# mail-intelligence-lab

A local-first .NET console tool that reads and understands a real Outlook mailbox via the Microsoft Graph API — before deciding what, if anything, to clean up.

> This is a personal engineering lab, not a product. Fase 0 (Discovery) is complete: authentication, full metadata read, and real attachment sizing against a real 20+ year old mailbox. No message has been modified or deleted by this tool — zero write operations exist in the code today.
